The Vision for JAI

Enterprise procurement platforms are inherently dense, requiring users to navigate vast data tables, multi-step supplier flows, and strict compliance rules. Jaggaer AI (JAI) was envisioned as an intelligent copilot embedded directly into the platform to reduce task friction, surfacing insights proactively and automating complex actions without pulling users away from their work.

Phase 01

Core Interaction Architecture & Entry Points

Before designing specific components, I established how JAI would enter the user’s workflow. The assistant needed to balance passive availability with timely, proactive intervention.

Proactive Triggers

JAI automatically initiates prompts based on user history, active page context, and supplier risk alerts.

Persistent Launchers

Floating entry trigger fixed in the bottom viewport, backed by a global top-toolbar trigger for universal access.

Context Persistence

Continuous conversation state retained as users navigate through deep, multi-page module trees.

Phase 02

Adaptive UI: The 3 View Modes

A single chat window cannot effectively serve both lightweight queries and deep data analysis. I designed a 3-tier view framework that dynamically shifts based on task complexity and screen real estate requirements.

View Mode Primary Purpose & Trigger Layout & Interaction Strategy
Small Chat Quick questions, simple status lookups, and proactive notifications. Compact floating window anchored to the bottom corner; keeps main page interaction primary.
Siderail / Copilot Side-by-side editing, document review, and multi-step assisted forms. Docked vertical sidebar that pushes or overlaps layout, enabling co-working alongside primary workflows.
Full Screen Mode Complex analytics, bid evaluation matrix comparisons, and heavy data views. Expanded viewport utilization featuring custom responsive grid systems for large data tables and charts.
Phase 03

Building the AI Component Library & Tokens

Standard UI components are inadequate for non-deterministic model outputs. I extended Jaggaer’s existing core design system with dedicated AI patterns designed to build trust and convey system intent.

// Discovery & Input Patterns
  • Command dropdown menus & prompt suggestion pills
  • Slash-command triggers for targeted tool routing
  • Active input indicators for attachments & context files
// Transparency & Trust Cards
  • Streaming text response states & inline reasoning models
  • Source attribution cards with direct platform deep-links
  • Confidence scoring metrics & verifiable data citations
// User Feedback Loops
  • In-line prompt editing and response regeneration
  • Thumbs up/down feedback mechanisms
  • Structured issue reporting modal slots
// Accessibility Standards
  • Strict keyboard navigation sequences across all 3 modes
  • Screen reader ARIA focus management for streaming text
  • High-contrast status tokens & clear visual states
Phase 04

Designing for Edge States & Latency

AI systems regularly encounter latency, API timeouts, and role restrictions. A critical part of my involvement was designing comprehensive state coverage so the UI gracefully degrades rather than breaking.

Managing Perceived Latency

Designed streaming text indicators, skeleton loaders, and multi-stage progress messages (e.g., "Analyzing supplier records...") to keep users engaged during long computations.

Error Handling & Recovery

Created structured error slots for model timeouts, API connection drops, and hallucination reporting, giving users clear paths to retry or escalate.

Permissions & Role Security

Configured UI permissions so restricted platform data and specific AI execution capabilities automatically hide or disable based on the user's system role.

Onboarding & Discovery

Partnered with Product Management to deploy targeted Pendo guides, introducing JAI’s capabilities to first-time users at high-value operational moments.

Outcomes & Collaboration

Validation, Iteration & Enterprise Delivery

Delivering JAI required continuous collaboration across weekly syncs with Product Managers and Engineering leaders to weigh design ambitions against technical timelines and API capabilities.

Customer Validation

Presented interactive prototypes and live production builds directly to enterprise customers to gather qualitative feedback.

Telemetry & Evals

Tracked launch button click-through rates and contributed to the setup of an internal AI evaluation tool to measure response accuracy over time.
